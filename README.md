# MyPlayer

Instaladores do MyPlayer, o player de música com visual de Windows Clássico.

**[Baixar a versão mais nova](https://github.com/BanePlayss/myplayer-releases/releases/latest)**

Abra o `MyPlayer-Setup-x.y.z.exe`. O Windows pode avisar que não reconhece o programa: clique em **Mais informações** e depois em **Executar assim mesmo**.

Depois de instalado, o MyPlayer se atualiza sozinho a partir daqui.
